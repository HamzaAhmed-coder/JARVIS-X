# JARVIS X 🤖

JARVIS X is a futuristic AI-powered desktop assistant inspired by JARVIS from the Iron Man universe. It combines voice interaction, natural-language commands, AI reasoning, desktop automation, system controls, web tools, productivity integrations, and a modern futuristic interface into a single assistant.

### Key Features

* 🎙️ Voice-based interaction
* 🧠 AI-powered command processing with Groq
* 🖥️ Windows desktop automation
* 🔊 Volume and brightness control
* 📸 Screenshot, lock, restart, shutdown, and sleep controls
* 🌐 Google and YouTube search
* 📅 Google Calendar integration
* 📧 Gmail integration
* 💬 WhatsApp automation
* 📁 File search and file management
* 🧮 Calculator and system utilities
* 🧠 Memory and recall capabilities
* 🎨 Futuristic JARVIS X interface
* ⚡ React + Vite + TypeScript frontend
* 🚀 FastAPI-powered Python backend

### Tech Stack

**Frontend:** React, Vite, TypeScript, Tailwind CSS, Framer Motion
**Backend:** Python, FastAPI, Groq
**Integrations:** Google Calendar, Gmail, WhatsApp, Web Search
**System Automation:** Windows APIs and Python tools

JARVIS X is a personal AI automation project focused on exploring how voice-driven AI, desktop automation, APIs, and modern interfaces can work together to create a practical AI assistant.
